# Payload Generation & Network Pivoting Lab

## Overview

This lab focused on offensive security concepts including payload generation, bind and reverse shells, Metasploit operations, network pivoting concepts, social engineering simulations, antivirus evasion concepts, and vulnerability research.

The exercises were conducted within controlled cybersecurity training environments using Kali Linux, Metasploit, Metasploitable, Windows systems, and Linux systems to better understand attacker methodologies and defensive considerations.

## Part A – Vulnerability Research

Researched and documented several major vulnerabilities and attack techniques including:

- Shellshock
- EternalBlue
- Heartbleed
- Apache Struts 2 RCE
- Apple iAmRoot
- POODLE
- Conficker
- Microsoft RPC DCOM
- Golden Ticket
- Silver Ticket
- Pass-the-Hash

Activities included:
- Reviewing CVEs and exploit references
- Understanding exploitation prerequisites
- Reviewing mitigations and defensive strategies
- Researching attacker techniques and persistence methods

---

## Part B – Payload Generation & Shell Access

Generated Windows and Linux bind/reverse shells using msfvenom and established shell access using Metasploit handlers.

Activities included:
- Creating executable payloads
- Hosting payloads through Apache
- Configuring Metasploit handlers
- Testing bind shell access
- Testing reverse shell callbacks
- Deploying payloads to Windows and Linux targets
- Troubleshooting payload execution issues

---

## Part C – Social Engineering & AV Evasion Concepts

Performed social engineering simulations using the Social Engineering Toolkit (SET) and explored payload obfuscation concepts with the Veil Framework.

Activities included:
- Creating cloned phishing pages
- Capturing submitted credentials in lab environments
- Modifying SET Toolkit templates
- Generating obfuscated payloads
- Researching antivirus evasion concepts
- Reviewing payload staging concepts

## Part D – Metasploitable Enumeration
