# Network Reconnaissance and Scanning Lab

## Overview
In this lab, I performed network reconnaissance and enumeration activities using Kali Linux within a controlled ethical hacking lab environment. The objective was to understand how attackers and security professionals identify hosts, services, operating systems, and exposed ports across a network using common offensive security tools and scanning techniques.

---

## Tools & Technologies
- Kali Linux
- Nmap
- Hping
- Tcpdump
- Wireshark
- Netcat
- Bash scripting
- Linux CLI

---

## Key Activities

### Network Discovery & Enumeration
- Performed Layer 2 ARP scans to identify active hosts and MAC addresses on the network.
- Conducted Layer 3 ICMP ping sweeps to discover live systems.
- Performed Layer 4 TCP and UDP scans to identify open ports and exposed services.

### Port Scanning & Fingerprinting
- Conducted:
  - TCP scans
  - UDP scans
  - SYN scans
  - ACK scans
  - Xmas scans
- Performed banner grabbing using Netcat to identify exposed services.
- Executed version scanning to identify software and service versions running on target systems.
- Used OS fingerprinting techniques to identify operating systems on remote hosts.

### Traffic Analysis
- Captured and analyzed network traffic using Tcpdump and Wireshark during scanning activities.
- Compared the amount of traffic generated by different scan types.

### Bash Automation
- Developed an interactive Bash scanning script that:
  - accepts a target subnet,
  - scans for active hosts,
  - identifies systems running common services,
  - and exports findings into organized text files including:
    - `ping-alive.txt`
    - `http-alive.txt`
    - `https-alive.txt`
    - `ssh-alive.txt`
    - `rdp-alive.txt`
    - `smtp-alive.txt`
    - `snmp-alive.txt`

### Security Analysis
- Evaluated weaknesses in the lab environment including excessive exposed ports and detectable services.
- Researched methods attackers may use to evade IDS/IPS and firewall detection, including:
  - packet fragmentation,
  - scan timing adjustments,
  - non-standard ports,
  - and encrypted communication channels.
