# Cross-Platform File Transfer & Shell Operations Lab

## Overview

This lab focused on performing secure and insecure file transfers between Windows and Linux systems within a controlled ethical hacking environment. The exercises explored multiple transfer protocols, shell operations, hash extraction, password cracking, and basic automation using both PowerShell and Bash.

The objective of this lab was to strengthen hands-on experience with common penetration testing and system administration techniques frequently encountered in cybersecurity and blue team operations.

---

## Skills Demonstrated

- Windows and Linux command-line operations
- Cross-platform file transfers
- FTP, SCP, SMB, HTTP, and TFTP usage
- Netcat bind and reverse shell concepts
- Password hash extraction and analysis
- John the Ripper password cracking
- PowerShell and Bash scripting
- Troubleshooting connectivity and authentication issues
- Documentation and operational note-taking

## Lab Activities

### Part A – File Transfers
Performed multiple file transfer techniques between Windows and Linux systems using:
- Interactive FTP
- Non-interactive FTP
- SCP
- SMB shares
- Apache web server downloads
- curl and wget
- TFTP troubleshooting

### Part B – Shell Operations
Configured and tested:
- Bind shells using Netcat
- Reverse shells between Windows and Linux systems
- Listener configuration and remote command execution

### Part C – Hash Extraction & Cracking
- Extracted password hashes from Windows systems
- Transferred hash files across systems
- Used John the Ripper to crack password hashes
- Managed and consolidated hash files for analysis

### Part D – Windows File Transfer Automation
- Transferred PuTTY utilities between Windows and Linux hosts
- Used PowerShell and SCP for automated file transfers
- Practiced SMB-based transfers and troubleshooting

### Part E – Linux File Transfer Automation
- Used curl and wget to retrieve files
- Automated Linux-to-Windows file transfers with SCP
- Practiced Bash scripting concepts for automation tasks
